# SnapPaste · 复制粘贴 + 截图贴图（合并版 v1.3）

把「一键复制粘贴工具」和 Snipaste 的核心功能合到一个程序里：一个热键体系、一份配置，文字和图片都管。
为什么能合、哪些没合，见 `docs/合并分析报告.md`。

## 打开就能用，热键不用自己设置

| 热键 | 功能 |
|---|---|
| F1 | 区域截图（框选后自动存档并钉在屏幕上，Esc 取消） |
| F3 | 贴剪贴板（图片钉屏 / 文字贴成便签条） |
| F6 | 多次复制（把当前剪贴板文字加入队列） |
| F7 | 顺序粘贴下一条 |
| F8 | 全部粘贴（回车/TAB/自定义分隔可选） |
| F9 / Shift+F9 | 删除最后一条 / 删除全部 |

贴图窗操作：拖动移动、滚轮缩放、双击关闭；右键菜单可标注、旋转 90°、调透明度、另存为 PNG。

## v1.1 新增：标注编辑器

F1 截图框选后不再直接钉图，先进标注编辑器：矩形 / 椭圆 / 箭头 / 直线 / 画笔 / 文字 / 马赛克，
6 种颜色、5 档粗细，可撤销、可清空，点「完成并钉图」才存档钉屏（也可以只保存、或放弃）。
已钉住的图右键「标注这张图」能再编辑。框选时左上角实时显示坐标和取色值（#RRGGBB），选区尺寸同步显示；
主界面截图列表选中一项会显示缩略图预览。
想改键：工具栏「热键设置」里录入，或改 `Config.ini` 的 `[HotKey]` / `[Snip]` 段。

## 运行（Windows）

```bat
pip install Pillow keyboard
python app\main.py
```

- Pillow 是截图/贴图的必需依赖；keyboard 是全局热键（不装也能用，只是热键仅在本窗口内生效）
- 打包成 exe：双击 `build_windows.bat`（PyInstaller，无加壳）
- 截图自动存到 `app\shots\`，主界面列表里点「钉住选中截图」可重新贴出

## 文件

- `app/main.py` 全部源码（文字队列 + 截图 + 贴图，无联网、无加壳）
- `app/Config.ini` 预设配置，兼容原一键复制粘贴字段，新增 `[Snip]` 段
- `docs/合并分析报告.md` Snipaste 功能分析、合并可行性与差距清单

## v1.2 新增：把差距清单补齐

- **窗口吸附**（Windows）：F1 后鼠标划过窗口会黄色虚线高亮整窗，单击直接截整窗，拖动仍是自由框选
- **OCR**：编辑器 / 贴图右键 / 历史列表都能识别图中文字，结果可一键复制或「加入文字队列」再用 F7 逐条粘贴
- **扫码**：识别二维码/条码内容，同样可复制或入队
- **模糊标注**：标注工具里新增「模糊」，和马赛克并列（打码敏感信息时任选）
- **历史画廊**：「历史画廊」按钮打开缩略图网格，可钉图/删除
- OCR/扫码是可选引擎：`pip install rapidocr-onnxruntime opencv-python-headless` 装一次、离线可用；不装不影响其他功能
